Publisher alternative for transit maps

Publisher is discontinued, but your network maps still need a tool. How Liniennetz-Editor fits, what it does differently and where its limits are.

Why an alternative became necessary

For many hobby planners, Microsoft Publisher was the tool of choice: intuitive, sufficient for network maps and without the overhead of a professional graphics program like InDesign or Affinity. The program was discontinued at the end of October 2026. Liniennetz-Editor was built because no fitting replacement existed for exactly this job.

The difference: describe instead of draw

In a drawing program you place lines, circles and text one by one and align them by hand. The editor turns that around:

Drawing programLiniennetz-Editor
Starting pointDraw shapes and linesDescribe the network: stops, lines, categories
ConnectionsDrawn and aligned by handAutomatic, 0°/45°/90° only with rounded bends
Parallel linesPlaced side by side individuallyBundled automatically, lane order adjustable
KeyBuilt and maintained by handGenerated from the network
Changing a stopRe-adjust parts one by oneMove it, connections follow

The result is a consistent, modern-looking map, and changes to the network take seconds instead of hours.

What the editor can do

  • Lines with trunk, branches and loops, several categories (e.g. frequent and infrequent service)
  • Stops with pass-through, direction-only service, temporary service and split locations
  • Line badges, key and line overview
  • Rivers, borders and areas as drawing objects, plus free text and images
  • Text styles and designs to save and reuse
  • Export as SVG, PNG and PDF

What it cannot do

  • Open Publisher files. There is no import for .pub files. You rebuild your network, see below.
  • Arbitrary layouts. Lines run only in 0°, 45° and 90° segments on the grid. Drawing objects such as rivers can be routed more freely.
  • Run as a desktop program. The editor is a web application and runs in the browser.
  • Replace a general graphics program. It is not meant for advertising graphics or photo montages.

How to switch

  1. Use your old map as a template. Export your Publisher map as an image and place it faintly behind the grid via Start › Background image…. It works as a tracing template and does not appear in the export.
  2. Bring over your stops. Create them or import them via CSV (header row Name;Column;Row).
  3. Assign lines. Set the stop order, choose colours and categories.
  4. Adjust the design. Set font, line thickness and symbols to match your previous style and save it as a design.

For a detailed step-by-step walkthrough, see the guide.

Your data stays with you

The editor runs entirely in your browser; there is no account and no server that sees your maps. Projects are stored as JSON files on your computer. Exported SVG files can be edited further in any vector program. The source code is on GitHub under the MIT licence.
