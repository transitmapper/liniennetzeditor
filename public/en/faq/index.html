Is Liniennetz-Editor free?

Yes. The editor is free, needs no account and is released under the MIT licence. The source code is on GitHub.

Where are my maps stored? Are they uploaded?

No. The editor runs entirely in your browser; maps are not sent to a server. You save your project as a JSON file on your own computer. The browser’s local storage only holds the list of recently opened files and recently used colours. For traffic statistics the site uses GoatCounter, without cookies and without map content; details are in the privacy policy (German).

Which browsers are supported?

The editor runs in the browser, most comfortably in Chrome, Edge and Opera: there it saves to the same file and can back up automatically after every change. In other browsers, “Save” downloads the project file.

Can I work offline?

There is no dedicated offline mode; you need an internet connection to open the editor. To work locally, download the source code from GitHub and start it with npm install and npm run dev (Node.js required).

How do I save my project?

On the Start tab, use Save (or Ctrl+S) to store a JSON file. In Chrome, Edge and Opera you can also enable Autosave: two seconds after your last change the editor writes to the linked file. The browser warns you before closing with unsaved changes. Ctrl+Z and Ctrl+Y undo and redo steps.

Which export formats are available?

SVG (vector graphic, editable), PNG (1×, 2× or 4× resolution, set in plan settings) and PDF. For PDF the browser’s print dialog opens; choose “Save as PDF”. The file name matches the plan’s title.

Is the export suitable for printing, including A3?

Yes. SVG and PDF are vector-based and stay sharp at any size. Page formats are A4, A3 and free, in landscape or portrait. For an important project, do a test print at the target size, especially to check label legibility.

Why does my SVG look different on another computer?

Fonts are not embedded in the SVG file. The default is “Segoe UI” with Arial as fallback. If the font is missing on the target computer, it is substituted and text widths shift. For sharing, PDF or PNG is the safer choice.

Can I open Microsoft Publisher files?

No, there is no import for .pub files. You can place your old map faintly behind the grid as an image and rebuild it. More on the Publisher alternative page.

How do I create many stops quickly?

Use the CSV import (Network tab › CSV… › Import). A stop list needs the header row Name;Column;Row, a line list Line;Colour;Route. Stops and lines can also be exported as CSV.

Can I reuse parts of a network?

Yes. In selection mode you mark stops and objects, export them as a selection and import them into another project, optionally shifted. Designs (fonts, colours, categories) are saved under Design and loaded into new projects.

May I use the maps commercially?

The editor itself is MIT-licensed, and the maps you create are yours. Rights to inserted images, background maps or data (such as timetable data) belong to their owners and you must clear them yourself. This is not legal advice.

I found a bug or have a request. Where do I report it?

Please open an issue on GitHub. Helpful details are the steps to reproduce, your browser and, if possible, the project file (without personal data).
